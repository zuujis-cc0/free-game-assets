# Accessibility

We want people to be able to find and use these assets whatever they browse with.

- **Pages:** every preview image in the README and galleries has alt text, and every file is also listed by name as a
  plain link, so the collection can be browsed with a screen reader or without images.
- **Game starters** ([zuujis-game-scripts](https://github.com/zuujiscom/zuujis-game-scripts)): each plays with a
  keyboard, a gamepad or touch, fits phone screens upright and sideways, and has a sound on/off button that is
  remembered.
- **Known limits:** contact sheets are pictures of many files at once, so their alt text describes the sheet, not each
  item (the file lists below them name every file). The starters do not yet offer remappable keys, colour-blind
  palettes or reduced motion.

Found a barrier? [Open an issue](https://github.com/zuujiscom/free-game-assets/issues/new?template=problem.yml) and
say what you were trying to do and what you use to browse or play.
