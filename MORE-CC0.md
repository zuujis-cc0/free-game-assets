# More CC0 assets for games

Other places with public-domain **CC0** assets that are useful for making games. These are links only: the files are not in this repository and were not made by Zuujis. Each source said CC0 when we checked in November 2026, but terms can change, so read the licence on the page you download from. Some creators also ask, as a courtesy, that you don't resell their files unchanged or claim them as your own.

[Back to the collection](README.md)

## 2D art and sprites

| Source | What you'll find |
| --- | --- |
| [Kenney](https://kenney.nl/assets) | Hundreds of packs: platformer, top-down, card, board, UI, space and city sprites, all CC0. [Kenney's licence note](https://kenney.nl/support) |
| [Kenney Fonts](https://kenney.nl/assets/kenney-fonts) | Pixel and vector game fonts |
| [Pixel Adventure 1 (Pixel Frog)](https://pixelfrog-assets.itch.io/pixel-adventure-1) | Pixel-art platformer characters, terrain, traps and items |
| [16x16 DungeonTileset II (0x72)](https://0x72.itch.io/dungeontileset-ii) | A pixel-art dungeon tileset with animated heroes and monsters |
| [itch.io CC0 game assets](https://itch.io/game-assets/assets-cc0) | itch.io's own list of asset packs marked CC0 |
| [OpenGameArt](https://opengameart.org/art-search-advanced?field_art_licenses_tid%5B%5D=4) | A large community library. This link searches only CC0 entries |

## 3D models

| Source | What you'll find |

| [Kenney 3D](https://kenney.nl/assets/category:3D) | Low-poly cars, tracks, castles, furniture, nature, space kits |
